项目需求：个人背单词小程序 / 网页（PWA 优先）
 
1. 背景与目标
 
做一个免费、可自建、开源的个人背单词工具，优先做成移动端网页/PWA（可选微信小程序）。核心场景：导入自己本周要背的专业单词和例句，能发音、能定时随身听、能自测检查、能提醒复习。
 
2. 目标用户
 
单个用户，主要用手机；通勤/走路时“听”，碎片时间“看+测”；词库以自己导入的专业词汇为主。
 
3. 核心功能需求（MVP 必须）
1. 自定义词库导入
	• 支持手动添加单词。
	• 支持导入 txt / csv / json（至少一种；建议 csv：单词、释义、例句、备注）。
	• 每个词条包含：单词、释义、例句（可选多个）、标签/批次（如“本周专业词”）。
	• 支持按批次/周计划管理词表。
	• 支持导出备份、删除/编辑词条。
2. 发音
	• 单词发音：英音/美音至少一种，最好可切换。
	• 例句发音：可播放整句。
	• 优先使用浏览器/系统 TTS，保证免费；可选缓存音频离线播放。
	• 可调语速。
3. 定时随身听
	• 选择词表/批次后生成播放列表。
	• 可设置：播放内容（单词/释义/例句/拼写）、重复次数、间隔时间、语速、口音、循环。
	• 支持定时关闭（如 15/30/60 分钟或循环 N 轮后停止）。
	• 支持后台/锁屏播放（PWA 用 Media Session API；小程序用 InnerAudioContext 后台播放能力）。
	• 锁屏/切 App 后尽量不中断；耳机线控可播放/暂停/下一首。
4. 检查单词 / 自测
	• 卡片翻转：看词想义、看义想词。
	• 拼写检查。
	• 选择题（可选）。
	• 记录“认识/模糊/不认识”，写入掌握度。
5. 复习提醒
	• 基于间隔重复算法（SM-2 或 FSRS）计算下次复习时间。
	• 首页显示“今日到期复习”。
	• 支持本地通知/订阅消息提醒（PWA Notification；小程序订阅消息）。
	• 错词/模糊词自动进入重点复习队列。 
4. 非功能要求
• 免费自建：开源，可部署到 Vercel / Cloudflare Pages / GitHub Pages 等免费平台；不强制付费 API。
• 本地优先：词库和进度存本地（IndexedDB / localStorage；小程序用 Storage），无需后端也能用。
• 移动端优先，界面简洁，单手可操作。
• 支持离线使用（至少已加载词库和 TTS 缓存可用）。
• 数据可导出/导入，防止丢失。
• 隐私：默认不上传用户词库。 
5. 技术建议
• 形态：PWA 网页优先（可“添加到主屏幕”），可选微信小程序。
• 存储：IndexedDB。
• 发音：Web Speech API / 系统 TTS；可选第三方 TTS 但必须可替换。
• 后台播放：HTML5 Audio + Media Session API；注意浏览器后台策略。
• 提醒：Notification API + Service Worker；小程序用订阅消息。
• 算法：SM-2 起步，后续可换 FSRS。 
6. 验收标准
• 能导入一份含“单词+释义+例句”的 csv，并在列表看到。
• 点单词和例句能发音，可调语速/口音。
• 能选“本周专业词”开始随身听，设置 30 分钟定时关闭，锁屏后仍播放。
• 能做卡片自测和拼写检查，结果影响掌握度。
• 到期单词出现在“今日复习”，能触发提醒。
• 刷新/重开后数据仍在，能导出备份。
• 项目可按 README 免费部署成功。 
7. MVP 不做
• 不做社交、排行榜、账号系统。
• 不做复杂后台管理。
• 不强制接入付费词典 API。
